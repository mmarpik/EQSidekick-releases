# EQSidekick

Installers and updates for EQSidekick, a raid tool for EverQuest: a live meter, triggers, raid sharing, signups and group planning.

Download **EQSidekick-win-Setup.exe** from the latest release. Installed copies update themselves from here.

What it does and how it compares with EQLogParser: [the EQSidekick white paper](WHITEPAPER.md).

Guilds that want their own raid server can download **EQSidekick-Server-<version>-win-x64.zip** from the same release; its README walks through setting it up.

EQSidekick was called Raid Meter until version 0.2.0; Raid Meter installs move over by themselves.
